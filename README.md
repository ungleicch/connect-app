## Team Access Check

To confirm you have access to this repository, follow the steps below and add your name at the bottom of this file.

### 1. Clone the repository

```bash
git clone https://github.com/ungleicch/connect-app.git
cd connect-app
```

### 2. Pull the latest changes

Always pull before you start working so you have the newest version:

```bash
git pull origin main
```

### 3. Create a new branch (recommended)

```bash
git checkout -b your-name-access
```

### 4. Edit this README

Add your name and a short comment in the **Access Confirmed** section below.

### 5. Stage and commit your changes

```bash
git add README.md
git commit -m "Add access confirmation for [Your Name]"
```

### 6. Push your branch

```bash
git push -u origin your-name-access
```

### 7. Merge into main and push

Either open a pull request on GitHub, or merge and push locally:

```bash
git checkout main
git pull origin main
git merge your-name-access
git push origin main
```

### Alternative: Work directly on main

If your team is working directly on `main`:

```bash
git checkout main
git pull origin main
# make your edits to README.md
git add README.md
git commit -m "Add access confirmation for [Your Name]"
git push origin main
```
